# Exercício 1 - Criação das Tabelas do Cadastro de Contatos

## Objetivo

Criar as tabelas necessárias para o projeto de Cadastro de Contatos no Protheus, configurando corretamente o dicionário de dados.

Foram realizadas as seguintes configurações:

- Criação da tabela no SX2;
- Criação dos campos no SX3;
- Criação dos índices no SIX;
- Inclusão dos parâmetros necessários no SX5.

---

## Desenvolvimento

Durante este exercício foi criada a estrutura inicial do projeto, permitindo que as próximas rotinas em ADVPL possam realizar consultas, inclusões, alterações e exclusões de registros.

Os principais componentes configurados foram:

### SX2

Cadastro da nova tabela utilizada pelo projeto.

### SX3

Definição dos campos da tabela, incluindo tipo, tamanho, validações e demais propriedades.

### SIX

Criação dos índices para otimizar pesquisas e ordenações.

### SX5

Cadastro das informações auxiliares utilizadas pelo sistema.

---

## Resultado

Após a configuração do dicionário de dados, a estrutura do projeto ficou preparada para o desenvolvimento das rotinas ADVPL dos próximos exercícios do módulo.
