# Exercício 1 - Conceitos Fundamentais

## a. Qual é a função do AppServer?

O AppServer é o servidor de aplicação do Protheus. Ele executa os programas ADVPL, processa as regras de negócio, acessa o banco de dados e envia as informações para o SmartClient.

## b. O que é o RPO?

O RPO (Repository) é o repositório onde ficam armazenados os programas ADVPL compilados. Quando uma rotina é executada, o AppServer busca esse programa no RPO.

## c. Para que serve o Configurador (SIGACFG)?

O Configurador é o módulo utilizado para administrar o Protheus. Nele podemos criar tabelas, campos, índices, menus, usuários e realizar configurações do sistema.

## d. Qual a diferença entre campo Real e campo Virtual no SX3?

O campo Real é gravado fisicamente no banco de dados. Já o campo Virtual não é armazenado no banco; seu valor é calculado durante a execução do sistema.
